# 🍽️ Food Delivery App

A full-stack **Food Delivery Web App** with role-based access for users and admins, real-time food menu management, and integrated **payment gateway** support.

---

## ✨ Features

### 👤 User Panel
- 🔍 Browse food by categories
- 🛒 Add to cart & checkout
- 💳 Online payment via Payment Gateway (e.g., Razorpay/Stripe)
- 🧾 View order summary & status

### 🛠 Admin Panel
- ➕ Add/Edit/Delete food items
- 📂 Manage categories & pricing
- 📊 View all orders and user info
- 🔐 Secured access via role-based routing
